I've been building for the web since 2009, when I designed and built the site for [Revista Exégesis](https://revista-exegesis.com), a collaborative magazine that is still online. Since then I've built web products of every size, from the database to the browser, including e-commerce platforms for international brands in video games, beauty, sportswear and consumer goods. Front end is where I go deepest, and these days I also lead engineering teams.

I still write code every day, now with AI agents in the loop.

## Now

```diff
- writing every line by hand
+ reviewing what the agents wrote
- one developer, one editor
+ a team of devs and their agents
- trying every new AI tool
+ keeping what survives review
```
